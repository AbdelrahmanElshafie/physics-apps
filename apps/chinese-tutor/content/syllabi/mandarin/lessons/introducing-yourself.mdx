title: Saying who you are

Greetings got you into a conversation. This lesson gets you through the next thirty seconds of
it: your name, what you do, where you're from. It also introduces 是 (shì), the closest thing
Mandarin has to "to be" — along with the strict limit on where it's allowed to appear.

## 1. Your name: 叫 (jiào)

<VocabCard hanzi="叫" pinyin="jiào" meaning="to be called" />

<GrammarPoint pattern="我叫 + name" title="The standard way to give your name">

我叫王明 — "I'm called Wáng Míng." 叫 literally means "to be called," and this is the everyday
phrasing, far more common than any construction using 是.

</GrammarPoint>

    { speaker: 'B', hanzi: '我叫王明。', pinyin: 'Wǒ jiào Wáng Míng.', meaning: "I'm called Wáng Míng." },
  ]}
/>

## 2. 是 (shì) — "to be", with one strict rule

<VocabCard hanzi="是" pinyin="shì" meaning="to be (am / is / are)" note="One form, always. 我是, 你是, 他是 — Mandarin verbs never conjugate for person, number, or tense." />

<GrammarPoint pattern="我是学生。" title="是 links two nouns">

我是学生 — "I am a student." 是 sits between two noun phrases (我 and 学生) and equates them. This
is what 是 is *for*, and — importantly — it is all it is for.

</GrammarPoint>

<Callout kind="warning" title="是 is for nouns only — never use it with an adjective">
This is the single most common early mistake, because English uses "is" for both: "She is a
teacher" (noun) and "She is tired" (adjective). Mandarin only uses 是 for the first kind. Saying
"她是累" for "she is tired" is wrong — adjectives work a completely different way, which is the
whole subject of the next lesson. For now: if what follows is a noun, use 是; if it's a
description, don't.
</Callout>

<Predict
  question="Which of these needs 是?"
  options={['"I am a teacher" — 老师 is a noun', '"I am tired" — 累 is an adjective', 'Both of them', 'Neither of them']}
  answer={0}
>
  Only the first. 我是老师 is correct because 老师 ("teacher") is a noun. "I am tired" uses an
  adjective, which takes a different pattern entirely — 是 would be wrong there.
</Predict>

## 3. Where you're from: country + 人

Nationalities are built with complete regularity — take the country, add 人 (rén, "person"):

<Compare
  columns={['Country', 'Nationality', 'Literally']}
  rows={[
    ['中国 Zhōngguó — China', '中国人 Zhōngguórén', 'China-person'],
    ['美国 Měiguó — America', '美国人 Měiguórén', 'America-person'],
    ['英国 Yīngguó — Britain', '英国人 Yīngguórén', 'Britain-person'],
  ]}
  caption="中 means 'middle' and 国 'country' — 中国 is literally the Middle Kingdom. 美国 and 英国 pair 国 with a syllable chosen to approximate the foreign name's sound."
/>

<GrammarPoint pattern="我是美国人。" title="Nationality is a noun, so it takes 是">

我是美国人 — "I am American." 美国人 is a noun ("an America-person"), not an adjective, so this is
exactly the noun-equals-noun case 是 exists for.

</GrammarPoint>

<Predict
  question="Given the pattern, how would you expect to say 'a French person', if France is 法国 (Fǎguó)?"
  options={['法国人 Fǎguórén', '人法国 Rénfǎguó', '法国是人', 'There is no pattern — it must be memorised separately']}
  answer={0}
>
  法国人. The country + 人 pattern is completely regular, so every nationality you'll ever need comes
  free once you know the country name.
</Predict>

<Dialogue
  caption="Putting it together"
  lines={[
    { speaker: 'A', hanzi: '你是中国人吗?', pinyin: 'Nǐ shì Zhōngguórén ma?', meaning: 'Are you Chinese?' },
    { speaker: 'B', hanzi: '不是，我是美国人。', pinyin: 'Bú shì, wǒ shì Měiguórén.', meaning: "No, I'm American." },
  ]}
/>

<Callout kind="note" title="吗 and 不 — previews, not detours">
That dialogue sneaks in two things with lessons of their own later: 吗 (ma) turns a statement into
a yes/no question by being added at the end, and 不 (bù) is "not". Both get proper treatment in
Phase 5. Recognise them here; you don't need to be able to use them freely yet.
</Callout>
