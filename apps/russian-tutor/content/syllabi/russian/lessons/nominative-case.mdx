---
title: The nominative case
summary: The dictionary form — the case every noun starts in, and the subject of a sentence.
readingMinutes: 15
---

Good news first: you already know the nominative case. Every noun you've learned so far — стол,
книга, окно, мужчина — has been shown to you in its nominative form, because that's simply what a
dictionary form *is*. This lesson gives that familiar thing a name and its second job, then adds
one genuinely new piece: how to make a noun plural.

## 1. Job one: the subject of a sentence

The nominative marks whoever or whatever is *doing* the action — the subject. No ending changes
from the dictionary form at all; this is the one case that doesn't transform the word.

<VocabCard word="студент" stressed="студе́нт" meaning="student (male)" />

<GrammarPoint pattern="Студе́нт чита́ет." title="Subject, unchanged">

Студент читает — "The student reads." Студент is doing the reading, so it stays in its plain
dictionary form: nominative. Compare this to the next lesson, where the exact same noun changes
its ending the moment it becomes the thing being acted on instead of the one acting.

</GrammarPoint>

## 2. Job two: naming and pointing things out with это

**Это** ("this is" / "that is" / "it is") is followed by the nominative, because grammatically
you're not acting on the thing — you're just naming it:

<Dialogue
  caption="Pointing things out"
  lines={[
    { speaker: 'A', word: 'Что это?', stressed: 'Что э́то?', meaning: 'What is this?' },
    { speaker: 'B', word: 'Это стол.', stressed: 'Э́то стол.', meaning: 'This is a table.' },
    { speaker: 'A', word: 'А это?', stressed: 'А э́то?', meaning: 'And this?' },
    { speaker: 'B', word: 'Это книга.', stressed: 'Э́то кни́га.', meaning: 'This is a book.' },
  ]}
/>

<Predict
  question="Это студент. The noun студент here is — grammatically — doing what job?"
  options={['Direct object', 'Subject being named/identified, same case as a true subject', 'Indirect object', "It's not in any case"]}
  answer={1}
>
  It's the nominative again — это doesn't act on студент, it just identifies it, so no case
  change happens. "This is a student" names a thing; it doesn't do anything to it.
</Predict>

## 3. The genuinely new part: making nouns plural

Nominative plural endings follow gender, the same pattern every case will from here on:

<Compare
  columns={['Gender', 'Singular ending', 'Plural ending', 'Example']}
  rows={[
    ['Masculine', 'consonant', '-ы', 'стол → столы'],
    ['Masculine', '-й', '-и', 'чай → чаи'],
    ['Feminine', '-а', '-ы', 'книга → книги*'],
    ['Feminine', '-я', '-и', 'семья → семьи'],
    ['Neuter', '-о', '-а', 'окно → окна'],
    ['Neuter', '-е', '-я', 'море → моря'],
  ]}
  caption="*книги, not книгы — see the spelling rule right below. This table covers the regular pattern; a handful of common nouns are irregular and just have to be learned as you meet them."
/>

<Callout kind="warning" title="The 7-letter spelling rule: ы never follows г к х ж ш щ ч">
This is a pure spelling rule, not a pronunciation one — these seven consonants are never followed
by the letter ы anywhere in Russian, in any word, for any reason. When a plural ending would
produce -ы after one of them, it's written -и instead. кни́га ends in г, so the plural is кни́ги,
not the "кни́гы" the basic pattern would otherwise predict. You'll see this same rule again inside
several case endings later, so it's worth fixing now rather than re-deriving it each time.
</Callout>

<Predict
  question="студе́нтка (female student) ends in -а, like книга. Its last consonant before that -а is к. What's the plural?"
  options={['студенткы', 'студентки', 'студентка (no change)', 'студентке']}
  answer={1}
>
  студентки. The basic -а → -ы pattern would give "студенткы", but к is one of the seven letters
  that can never be followed by ы — so it becomes studе́нтки instead, exactly like книга → книги.
</Predict>
